# 猫の手

仕事のちょっとした手間を、キー1つで片付ける Windows 常駐アプリです。次の4つができます。

- Acrobat で表示しているPDFのページを、高画質な画像としてコピーする
- エクスプローラーで選んだファイルを、まとめて開く
- エクスプローラーで選んだファイルやフォルダーのパスを、人に伝えやすい形でコピーする
- エクスプローラーや保存の画面で、同じ階層の隣のフォルダーに移る

## インストール

**[最新版をダウンロード](https://github.com/nekosama-orz/NekoNoTe/releases/latest/download/NekoNoTe-win-Setup.exe)**

ダウンロードした `NekoNoTe-win-Setup.exe` を実行します。管理者権限は不要です。

「WindowsによってPCが保護されました」と表示されたら、「詳細情報」から「実行」を選びます。コード署名をしていないために出る表示です。

インストールすると、画面右下のタスクトレイに猫の手のアイコンが出ます。次回からは Windows の起動時に自動で常駐します。自動起動は、トレイメニューの「Windows 起動時に常駐する」で切り替えられます。

## PDFのページをコピーする

1. Acrobat で、PCに保存されたPDFを開きます。
2. コピーしたいページを表示して、`Ctrl+Shift+C` を押します。
3. Acrobat の右下に「コピーしました」と出たら、Excel などに貼り付けます。

コピー中は1秒ほど Acrobat の操作が止まります。時間がかかるときは「コピー中です…」と表示されます。

### 開いているタブのページをまとめてコピーする

`Ctrl+Shift+C` を長押し(0.5秒)すると、開いているタブすべてについて、表示中のページをコピーします。長押しになると「全タブをコピーします」と表示されます。Excel や Word に貼り付けると、ページごとの絵が約6mmずつ空けて横に並びます。

- タブを順に切り替えて読み取るので、タブの数だけ時間がかかります。終わると元のタブに戻ります。
- コピーできるのは20タブまでです。読み取れないタブが1つでもあると、コピーしません。
- Excel と Word 以外のアプリでは、アプリによって、ページごとの絵になったり、全ページを横につなげた1枚の画像になったりします。ページの画像が大きいとき(大きなスキャンのPDFが多いときなど)は、Excel や Word でも1枚の画像になり、「大きいため1枚の画像」と表示されます。

### 貼り付ける大きさを変える

タスクトレイのアイコンを右クリックし、メニューの「コピーする大きさ」を%で指定します。100%でコピーすると、貼り付けたときに元のページと同じ大きさになります。変更は次のコピーから反映されます(すでにコピーしたものや、貼り付けたものの大きさは変わりません)。

### コピーできないとき

赤い枠の通知に、原因と対処が表示されます。よくあるものは次のとおりです。

- **クラウド上のファイル:** PCに保存してから開いてください。
- **保存していない変更:** 注釈や入力の内容は、保存してからコピーしてください。
- **パスワード付きのPDF:** コピーできません。
- **「入力欄が開いています」:** Acrobat で Esc を押してから、もう一度試してください。

## 選んだファイルをまとめて開く

エクスプローラーかデスクトップでファイルを選び、`Ctrl+Q` を押します。Excel、PDF、画像のように種類が違っても、それぞれ既定のアプリで開きます。

- フォルダーは開きません。
- 16件以上を開くときは確認が出ます。
- PDFを開く既定のアプリが Acrobat のときは、`Ctrl+Q` を長押し(0.5秒)すると、選んだPDFを Acrobat の新しいウィンドウにまとめて開きます(「新しい窓で開きます」と表示されます)。`Ctrl+Tab` で選んだPDFどうしだけを切り替えて見比べられます。短く押したときは、PDFもいつもどおり開きます。
- ZIP の中のファイルは開けません。開けなかったファイルは通知でお知らせします。

## パスをコピーする

エクスプローラーかデスクトップで項目を選び、`Ctrl+Alt+C` を押します。エクスプローラーで何も選んでいなければ、開いているフォルダーのパスをコピーします。

```
C:\Users\example\Documents\
・images\
・2.txt
・10.txt

C:\Users\example\Documents\images\old\photo.png
```

- 同じフォルダーで2件以上選んだときは、フォルダーの下に並べます。フォルダーが違うものは空行で区切ります。
- 1件だけ選んだときは、ファイルでもフォルダーでも、そのパスだけをコピーします。
- ファイル1件のときもフォルダーの下に並べたいときは、タスクトレイのアイコンを右クリックし、メニューの「ファイル1件もフォルダーの下に並べる」にチェックを付けます。受け取った人は1行目でフォルダーを開き、2行目でファイルを探せます。まとめたパスにも同じ設定が使われます。
- フォルダーの末尾には `\` を付けます。
- ネットワークドライブは `\\server\share\...` の形に変換します。
- 並び順はエクスプローラーの名前順に合わせ、フォルダーを先に並べます。

### 別々のフォルダーのパスをまとめる

項目を選んで `Ctrl+Alt+C` を長押し(0.5秒)すると、「まとめたパス」に足して、それまでの分と合わせてコピーします。フォルダーを閉じても、途中でほかのものをコピーしても、まとめたパスは残ります。作業を1つずつ進めて、最後にまとめて報告するときに使えます。

- 足した項目を選んで、もう一度長押しすると外れます。
- キーを忘れたときは、タスクトレイのアイコンを右クリックします。「まとめたパス」の項目にキーが書いてあります。
- 「まとめたパス」にマウスを合わせると、いまの一覧が見られます。項目を押すと外れます。「まとめてコピー」でもう一度コピーし、「空にする」で一覧を空にします。
- 短く押したときは、まとめたパスに触れず、選んだ項目だけをコピーします。
- まとめたパスは、猫の手やPCを再起動しても残ります。「空にする」を押すまで消えません。ほかの人に読まれないよう、暗号化してPCに保存しています。

## 隣のフォルダーに移る

エクスプローラーで `Alt+Shift+↓` を押すと、同じ階層にある次のフォルダーに移ります。`Alt+Shift+↑` で前のフォルダーに戻ります。

ファイルを保存する画面や開く画面(Edge の「名前を付けて保存」など)でも使えます。入力していたファイル名はそのまま残ります。

- 並び順は名前順です。エクスプローラーを更新日時順などで表示していても、名前順に移ります。
- 隠しフォルダーは飛ばします。
- 端のフォルダーでは「次のフォルダーはありません」と表示します。
- PC やライブラリのように、上の階層がない場所や実際のフォルダーでない場所では使えません。
- フォルダーを選ぶ画面と、アプリが独自に作った保存の画面では使えません。キーはそのままアプリに届きます。

## キーについて

- `Ctrl+Q` と `Ctrl+Alt+C` は、ファイル一覧を操作しているときだけ効きます。名前の変更中やアドレスバーに入力しているときは効きません。
- `Ctrl+Shift+C` は、Acrobat を操作しているときだけ効きます。
- `Alt+Shift+↓` と `Alt+Shift+↑` は、エクスプローラーと、ファイルを保存する画面や開く画面で効きます。
- ほかのアプリでは、キーはそのままそのアプリに届きます。
- キーの判定のためにキー入力を監視しますが、内容を記録したり送信したりはしません。セキュリティソフトが警告を出した場合は、この動作が原因の可能性があります。

## 使わない機能を止める

タスクトレイのアイコンを右クリックし、機能の名前を押すとオンとオフが切り替わります。オフにした機能のキーは、ほかのアプリにそのまま届きます。押してもメニューは開いたままなので、続けて切り替えられます。メニューの外をクリックすると閉じます。

## 更新

起動時と、常駐中は24時間ごとに更新を確認し、新しい版があれば自動で更新して再起動します。すぐに確認したいときは、トレイメニューの「再起動」を押します。

更新を確認できないときは、10分おきに何度かやり直し、それでもだめなら「更新を確認できませんでした」と通知します。通知が続くときは、このページから最新版をダウンロードして実行すると更新できます。トレイメニューの「使い方」で、このページを開けます。

## アンインストール

トレイメニューの「アンインストール」、または Windows の「設定 > アプリ」から削除します。設定とログも削除されます。

## 困ったとき

まずトレイメニューの「再起動」を試してください。直らなければ「診断情報をコピー」を押して、開発者に送ってください。自動で送信されることはありません。

起動しなくなったときは、`NekoNoTe-win-Setup.exe` を実行し直してください。
